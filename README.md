# Blockchain laboratory portfolio

This repository contains practical laboratory assignments and technical
implementations completed as part of the Blockchain engineering curriculum.
The work focuses on cryptographic primitives, distributed ledger data
structures, consensus protocols, and immutability validation.

## Repository structure

- [TP - 01: SHA-256 hashing, blockchain data structure, and Proof of Work](./TP%20-%2001):
  Implementation of cryptographic hashing, block linking, Proof of Work (PoW)
  mining, chain verification, and data tampering resistance analysis.

## Tech stack

- Language: Python 3
- Environment: Jupyter Notebook, VS Code
- Standard libraries: `hashlib`, `time`, `json`
